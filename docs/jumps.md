# Neovim 跳转 / 导航手册

> 本手册覆盖当前配置中所有跳转相关键位，按"距离/粒度"分层讲解。
> 涉及的配置文件：
> - 基础移动/窗口/分屏/标签页：`lua/config/keymaps.lua`
> - 字符/结构快速跳转：`lua/config/plugins/leap.lua`（flash.nvim）
> - 搜索与翻结果：`lua/config/plugins/search.lua`（hlslens / grug-far）
> - 语义跳转：`lua/config/plugins/lspconfig.lua`
> - 文件/工程级跳转：`lua/config/plugins/telescope.lua`

---

## 0. 设计总览

物理键盘是 Colemak 布局，方向键 `u/e/n/i` 列全部落在右手（`n`=左、`i`=右在 HOME 行，`e`=下、`u`=上在其上方/中间），跳转键位围绕两条主线设计：

1. **方向键统一为 `u/e/n/i`**（对应标准 vim 的 `k/j/h/l`），并贯穿到窗口、分屏、标签页：
   - `<leader>u/e/n/i` 切换窗口；`s<u/e/n/i>` 分屏；`t< n/i>`、`tm<n/i>` 切换/移动标签页
2. **跳转按目标粒度分层**，越往上层跳得越远：

| 层 | 要跳的东西 | 入口 |
|---|---|---|
| 屏幕内、字符级 | 任意可见字符 | Flash `<leader>k` |
| 结构级 | 语法树节点（函数、块、参数…） | Flash `gs` / `gS` |
| 语义级 | 定义、实现、类型、引用 | LSP `gd` / `gi` / `go` / `gr` |
| 文本级 | 搜索词、匹配括号、诊断 | `/` + `=/−`、`,.` |
| 文件级 | 打开/切换文件、缓冲区、标签页 | Telescope `<C-p>` / `<C-w>` / `<c-t>` |

## 1. 基础移动（keymaps.lua）

所有移动键映射（normal / visual 模式）：

| 键 | 动作 | 说明 |
|---|---|---|
| `u` / `e` / `n` / `i` | 上 / 下 / 左 / 右 | Colemak 版 `k/j/h/l`（右手紧凑方向列） |
| `U` / `E` | 上移 5 行 / 下移 5 行 | 大范围滚动 |
| `<C-U>` / `<C-E>` | 屏幕向上 / 向下滚 5 行 | 替代翻页，平滑滚动 |
| `gu` / `ge` | 上一 / 下一"屏幕行" | 折行（wrap）时按显示行移动 |
| `N` / `I` | 行首 / 行尾 | Colemak 版 `0` / `$` |
| `h` | 单词尾 | Colemak 版 `e` |

配套的"操作符 + 方向"组合（复制/修改一段然后跳到目标）：

| 键 | 实际执行 | 说明 |
|---|---|---|
| `cn` / `ci` | `ch` / `cl` | 向左 / 向右修改 1 个字符 |
| `ck` | `ci` | "向内修改"前缀（如 `ckw` = 改词内部） |
| `c,.` | `c%` | 修改到匹配括号处 |
| `yh` / `yk` | `ye` / `yi` | 复制到词尾 / "向内复制"前缀 |

其他常用跳转：`,.` 跳到匹配括号（`%`），`,v` 选中匹配块（`v%`），`za` 折叠开关（`<leader>o`）。

## 2. Flash 快速跳转（leap.lua → flash.nvim）

### 键位

| 键 | 模式 | 动作 |
|---|---|---|
| `<leader>k` | n / x | 字符跳转：输入 2~3 个字符 + 1 个标签键，跳到**当前窗口**内任意可见位置 |
| `gs` | n / o / x | Treesitter 跳转：列表出语法节点，输入标签跳到**当前窗口**的节点（支持范围选中整个节点） |
| `gS` | n / o / x | Treesitter 搜索：在**所有窗口**搜索并跳转结构节点 |
| `/` | o / x | 操作/可视模式下触发 Flash：`d<leader>…` 或 `y/` 后直接选目标，一次完成"删除/复制 + 跳到目标" |

### 工作机制与当前选项

- **标签集**：`arstneiowfuydh` 共 14 个，带彩虹色高亮；输入已在用过的标签会**复用**（`reuse = "all"`），近处的目标优先分配不重复的标签
- **标签显示**：`inline` 内联在匹配之后（treesitter 模式在节点首尾各一个标签）
- **跳转历史**：跳转计入 jumplist（`jump.jumplist = true`），可用 vim 的 `<C-o>` / `<C-i>` 回退
- **搜索范围**：仅**当前窗口的可视区域**（生成匹配的范围是视口首行到末行，见 flash 源码 `cache.lua` 的 `topline→botline`）；屏幕外的目标不会出现标签——先把目标滚入视野（`<C-U>`/`<C-E>` 平滑滚动）再跳。这与 `/` 的全文搜索是刻意的差异（见 §0 分层）
- **光标处的匹配被跳过**：`label.current = false` 时，光标正所在的匹配不分配标签（跳到自己脚下没意义）；若想显示，把 `leap.lua` 的 `label.current` 改为 `true`
- **标签不够时按距离分配**：屏内匹配数超过 14（标签总量）时，`label.distance = true` 让最近的匹配优先拿标签，远处的暂时无标签，继续输入前缀过滤后补上
- **不自动跳**（`autojump = false`）：所有跳转都需显式输入标签，不会误触
- **标签输入不受移动重映射干扰**：flash 以无重映射方式读取标签键，`u/e/n/i` 作标签时不会触发移动；且标签集 `arstneiowfuydh` 在 Colemak 下大部分（`arst` `neiodh` 共 10 个）落在 HOME 行，击键距离短
- **提示条**：底部 `⚡` 提示窗显示前缀输入
- **上下文跳转 `[c`**（treesitter-context）：跳到当前所在函数/块/类的最近上下文起点，可与 `gs` 配合——先 `[c` 回结构头，再用 `gs` 在结构间移动

### 刻意关闭的默认键位（防止冲突）

flash 自带的默认键位 `s`（单字符）、`S`（结构）、`x`（多窗口搜索）、搜索模式 `/` 都**关闭**了：

- `s` 兼作两职：单按是 **substitute 操作符**（editor.lua 后加载覆盖了 keymaps.lua 的 `<nop>`），`s<u/e/n/i>` 是分屏前缀；两键需快速敲击避免误触发代换（见 §9-6）
- `/` 保留给原生搜索 + hlslens（见 §3），避免两套搜索提示叠加
- `char.enabled = false`、`search.enabled = false`，只通过显式 `<leader>k` 调用

## 3. 搜索与翻结果（search.lua → hlslens / grug-far）

| 键 | 动作 |
|---|---|
| `/`（及 `?`） | 原生搜索，hlslens 在行尾预览匹配位置 |
| `=` | 下一个匹配（`n`）；`-` | 上一个匹配（`N`） |
| `*` / `#` / `g*` / `g#` | 光标下单词搜索（含 hlslens 预览） |
| `<leader><CR>` | 清除搜索高亮（nohlsearch） |
| `<leader>F` | grug-far：基于 ripgrep 的**工程级查找替换** |

> 为什么翻结果不是 `n` / `N`：这两个键被 §1 的 Colemak 移动键占用（`n`→左、`N`→行首），
> 所以用相邻的 `=`（下一处）和 `-`（上一处）代替，左右对称、免 shift。

### 3.1 查找入口全景（按查找范围）

整个配置的查找能力约 20 个入口，按"目标范围"分五层：

| 层 | 入口 | 查什么 / 怎么查 | 怎么跳到结果 |
|---|---|---|---|
| 屏幕内字符 | `<leader>k` | 输 1~3 字符前缀，屏幕内出标签 | 输标签直接落点（查=跳） |
| 屏幕内结构 | `gs` / `gS` | 语法节点列表（单窗口 / 全部窗口） | 标签跳，o·x 模式可范围选中 |
| 操作符目标 | o·x 下 `/` | 查找 yank/delete 的目标 | 一次完成 |
| 当前文件文本 | `/` `?` | 增量正则搜索（`incsearch=true`） | `=`/`-` 循环，回车落点 |
| 光标词 | `*` `#` `g*` `g#` | 直接搜光标下单词 | `=`/`-` 循环 |
| 当前文件行 | `<C-_>` | 行内容模糊搜索（fuzzy） | picker 选中即跳 |
| 工程文本 | `<leader>F` | rg 正则 / 固定串，带预览（偏替换） | 结果列表选跳 |
| 文件名 | `<C-p>` | 路径模糊 | picker 选中即跳 |
| 最近文件 | `<C-h>` | oldfiles 列表 | 选中即跳 |
| 缓冲区 | `<C-w>` | buffer 列表 | 选中即跳 |
| 命令 | `:`（normal）/ `<C-q>` | 命令名模糊 | 选中执行 |
| 诊断 | `<leader>d` | 错误列表 | 选中跳；`<leader>=`/`-` 顺序翻 |
| 语义 | `gd` `gi` `go` `gr` | 定义 / 实现 / 类型 / 引用 | 直接跳；引用出列表 |

> **已知空白**：无全局内容搜索（live_grep）入口，`<c-f>` 的 `grep_string` 被注释；
> 跨文件"轻量搜内容"目前只能走 `<leader>F` 或先 `<c-p>` 找文件再 `<C-_>`。
> 完整缺口清单（符号大纲、quickfix 导航、harpoon 等）见 §9。

### 3.2 查找→跳转的三种耦合模式

1. **一体式（查完即跳）**——Flash `<leader>k` / `gs` / `gS`：无中间态、零确认；适用"目标在屏幕内/结构可见"。
2. **二次确认式（查完选）**——Telescope 系列：列表可预判、可继续筛；适用"目标在文件/工程里、位置未知"。
3. **翻页式（查完循环）**——`/`+`=`/`-`、诊断 `<leader>=`/`-`：语境连贯，适合顺藤摸瓜逐个看。

**搭配逻辑**：屏幕内可见 → `<leader>k`；文件深处不确定 → `/` 或 `<C-_>`；跨文件 → `<leader>F`；语义 → `gd`/`gr`。
三模式互补不重叠，是配置文件刻意分层的结果（flash 的默认 `/`/`x` 键位已关闭防冲突，见 §2）。

### 3.3 查找方式的四大区别

**① 匹配方式**（"命中"的判断标准）

| 匹配语义 | 入口 | 行为 |
|---|---|---|
| 字面 / 正则 | `/` `?` `*` `#`、`<leader>F` | 精确或正则；smartcase（全小写不区分大小写，含大写则区分） |
| 前缀 → 标签 | `<leader>k` | 字面前缀（flash 默认 `exact`，`fuzzy` 被注释），随后输标签落点 |
| 模糊子序列 | `<C-p>` `<C-_>` | fzf 子序列匹配（输 `abc` 可命中 `aXbYc`），结果按相关性排序 |
| 语法结构 | `gs` / `gS` | 匹配语法树节点，与文本内容无关 |
| 符号语义 | `gd` `gi` `go` `gr` | LSP 解析的符号，工作区跨文件 |

**② 搜索范围**

| 范围 | 入口 |
|---|---|
| 屏幕内 | `<leader>k`、`gs` |
| 全部窗口 | `gS` |
| 当前文件 | `/` `?` `*` `#` `<C-_>` |
| 工程（文件名） | `<C-p>` |
| 工程（内容） | `<leader>F`（轻量内容搜索缺失，见 §9-1） |
| 历史 / 缓冲区 | `<C-h>`、`<C-w>` |
| LSP 工作区 | `gd` 系 |

**③ 结果形态**：即刻落点（flash 标签即目的地）｜ 单点 + 循环（`/` → `=`/`-`）｜ 列表选择（telescope）｜ 直接跳（`gd`，多候选时出列表）

**④ 查-跳耦合**：一体式（flash，无中间态）｜ 分离 + 循环（`/`）｜ 分离 + 选择（telescope）

### 3.4 易混淆入口逐对对比

- **`/` vs `<leader>k`**：`/` 全文正则、结果需循环到达、留高亮；`<leader>k` 只限屏幕内、字面前缀、输标签直达、无残留。**目标文本可见 → `<leader>k`；不可见 → `/`。**
- **`/` vs `<C-_>`**：`/` 逐匹配正则、按文档顺序；`<C-_>` 整行模糊、按相关性排序、按行落点。**要找"某一次出现"用 `/`，要"跳到某行"用 `<C-_>`。**
- **`<C-p>` vs `<leader>F`**：前者按**文件名**，后者按**文件内容**（偏替换）。
- **`gs` vs `gd`**：`gs` 语法结构（无需 LSP，o/x 模式可把节点当对象操作）；`gd` 符号定义（需 LSP）。
- **`*` vs 全局词搜**：`*` 只在当前文件按整词精确搜；**配置暂无"全局搜光标词"入口**（见 §9-1）。

### 3.5 实际用法要点

- **`<leader>k`**：按 → 输 1~3 个字符（屏幕出现彩虹标签）→ 按标签字母落点；同屏连续跳可复用已用标签。
- **`/`**：输正则（smartcase 自动）→ `=`/`-` 循环 → 回车落点 → `<leader><CR>` 清高亮。
- **`<C-_>`**：输子序列（如 `get_user`）→ 回车跳到该行。
- **`gs` / `gS`**：按 → 节点出现标签 → 单键落点；o/x 模式下 `d`/`y` + `gs`，先按 `d` 再按 `gs` 输标签，直接对节点删 / 拷。
- **`<leader>F`**：输正则 → 面板预览 → 回车跳原文 / 批量替换。
- **`gd`** 直达定义；**`gr`** 列出所有引用选跳。

## 8. 踩坑记录（本次审查修复）

- **`gi` 双绑定**：telescope 全局 `gi`→git_status 与 LSP buffer-local `gi`→implementation 冲突，
  行为取决于 buffer 是否 attach 了 LSP。→ git status 迁移到 `<leader>gs`。
- **`<leader>-`/`<leader>=` 方向**：两键原本都跳"上一个"诊断（复制粘贴错误），
  `<leader>=` 已改为下一个。
- **`tt` 遮蔽 `t` 移动**：`tt` 绑定 flash treesitter 会让 `t t`（till t）失效、且 `t` + 字母受 timeout 延迟。
  → 改为 `gs`（单窗口）+ `gS`（跨窗口），释放 `t`。
- **死配置**：flash 的 `treesitter_search`（多窗口）此前配了模式但没绑键，现在有 `gS` 入口。
- **`gs` 曾被 antovim 抢占**：`theniceboy/antovim`（光标词换反义词，原为 jwarby/antovim 的 fork）默认把 `gs` 绑为 `:Antovim`，覆盖了 flash 的结构跳转。已**整体移除**该插件（editor.lua + `Lazy clean`），`gs` 恢复为 flash 自带 keys 绑定；日后若想用反义词功能，可装 jwarby/antovim 并自行换键。

修改这类键位时，注意保持"方向即 `u/e/n/i`"的布局约定，并同步更新本手册。
